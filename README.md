# Pertin Haltia для Lenovo Tab P11 (TB-J606L)

Слой устройства для Lenovo Tab P11 **TB-J606L** (Snapdragon 662, SM6115,
плата `bengal`). Оболочка и программы — общие, в [Haltia](https://github.com/haltia-de/haltia).
Решения порта — в [плане](https://github.com/haltia-de/haltia/blob/main/docs/plans/tab-p11.md).

> **Прошивать нечего.** Репозиторий заведён 23 октября 2026. Образа
> для записи здесь ещё нет. Загрузчик лабораторного экземпляра открыт,
> Android снова работает со слота B. Копий `boot`, `dtbo`, `vbmeta`,
> `modemst`, `fsg`, `fsc` и `persist` ещё нет, поэтому разделы не
> записываются и активным не делается слот A. Одноразовый образ из
> дерева J606F уже загружался и увёл планшет в перезагрузки. Его судьба
> записана в ADR 0101.

*English summary: the device layer for the Lenovo Tab P11 TB-J606L. No
boot image is published from this repository yet. Do not flash the
tablet. Do not boot the J606F one-shot image again.*

## Для какого устройства

Только **TB-J606L** (LTE, сборка RU на лабораторном экземпляре): Android 11,
`LenovoTB-J606L_RU`, ядро производителя 4.19. На TB-J606F (только Wi-Fi)
этот порт не проверялся. В основном ядре Linux есть дерево J606F
(`sm6115p-lenovo-j606f.dts`). Это соседняя модель, не эта.

## Состояние на 27 октября 2026

Haltia стоит вторым системой рядом с Android (слот B, Linux в `recovery_b`
и разделе `haltia`). Работают экран, касание с двойным тапом, Wi-Fi,
Bluetooth, звук, микрофоны, зарядка и батарея, поворот, кнопки, фронтальная
камера через libcamera. Не работают пока основная камера, наушники, OTG,
сон в s2idle (#23).

- `docs/dual-boot.md` — как устроена двойная загрузка и что работает;
- `docs/reinstall.md` — сборка и чистая установка образа;
- `docs/camera.md` — исследование и запуск камер;
- `kernel/README.md` — патчи ядра.

## Что было известно 23 октября

Досье снято чтением 23 октября 2026, подробности в `docs/dossier.md`.

| Узел | Состояние |
|---|---|
| Загрузчик | открыт 23 октября 2026, состояние orange. `userdata` стёрт. В разделы образ не записывался. Android снова на слоте B |
| Слоты A/B | Android на слоте B. Слот A вечером того же дня в загрузку не пошёл. Haltia по плану займёт неактивный слот только после копий |
| Экран 1200×2000, 60 Гц, плотность 240 | в Android работает. В основном ядре для J606F есть панель Novatek NT36523W и simplefb. На этом J606L не проверялось |
| Касание Novatek | в Android есть (`NVTCapacitiveTouchScreen`). В дереве J606F узла касания нет |
| Звук, зарядка, сон, Wi-Fi, поворот | в Android есть. В строке реестра Haltia основное ядро на этой модели поднимается без касания, звука и зарядки |

Повседневная планка, после которой модель может войти в линейку: экран,
касание, Wi-Fi, звук, сон, кнопка питания, поворот. LTE, камера, перо,
клавиатура и GPU в эту планку не входят.

## Копии разделов

Снятой копии `boot`, `dtbo`, `vbmeta` и идентификационных разделов ещё
нет. Сравнение способов и кандидат на чтение —
`docs/partition-backup.md`. Проверенный на этом экземпляре способ ещё
не установлен. Записка не разрешает перезагрузку, временную загрузку,
вход в EDL и запись. Первый шаг, который меняет состояние, и условия
остановки до него записаны там.
