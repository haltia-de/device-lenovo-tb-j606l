# 0100. Порт TB-J606L следует плану Haltia

## Статус

Принято 23 октября 2026.

## Контекст

Haltia уже описала этот планшет как второе устройство в
[плане](https://github.com/haltia-de/haltia/blob/main/docs/plans/tab-p11.md).
Автор сказал приступать к работе. Отдельного слова на запись планшета
не было.

## Решение

Этот репозиторий — слой устройства для Lenovo Tab P11 TB-J606L.
Решения плана он не пересматривает: основное ядро, Haltia на неактивном
слоте, Android остаётся на текущем, оболочка одна, первый показ через
`phoc` на DRM.

Пока автор отдельно не разрешит запись, репозиторий не содержит команд,
которые разблокируют загрузчик или прошивают планшет.

## Последствия

Образ Pertin Haltia для этой модели собирается здесь только до тех пор,
пока Haltia на планшете не загрузится. Дальше сборка переезжает в
`pertin-haltia`, как записано в ADR 0004 корневого репозитория.
