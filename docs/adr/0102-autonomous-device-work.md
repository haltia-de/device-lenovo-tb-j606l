# 0102. Работа с планшетом без отдельного согласования каждого шага

## Статус

Принято 26 октября 2026. Заменяет ограничения на запись из ADR 0101 и
раздела «Writes» в `AGENTS.md`. Отменять ADR 0101 задним числом это
решение не должно: он остаётся записью о 23 октября.

## Контекст

Критичный резерв снят 24 октября: 17 разделов (`boot`, `dtbo`, `vbmeta`,
`vbmeta_system`, `recovery` обоих слотов, `modemst1`, `modemst2`, `fsg`,
`fsc`, `persist`, `misc`) и обе копии GPT всех шести LUN. Копии лежат вне
Git, проверены двумя проходами и продублированы на второй диск. Чтение
через EDL (`qdl --storage=ufs` с штатным `prog_firehose_ddr.elf`) на этом
экземпляре проверено, `adb reboot edl` переводит планшет в режим 9008.

С 24 по 26 октября прошла серия одиночных проб RAM-загрузки, каждая
со своим ревью и одноразовым разрешением. Android B каждый раз
восстанавливался. Linux-ядро и PID1 по косвенным данным стартуют, USB
гаджет на хосте не виден. Темп в одну переменную за прогон оказался
слишком медленным для цели.

26 октября автор сказал: директива в `AGENTS.md` устарела, цель — результат,
любые действия с планшетом допустимы без согласования.

## Решение

Агент сам решает, что делать с лабораторным экземпляром: `fastboot boot`,
`flash`, смену слота, EDL-чтение и запись, переразметку. Отдельного слова на
каждый шаг больше нет.

Обязательными остаются три вещи:

1. Резерв из ADR 0101 не трогается и не перезаписывается. Перед записью
   раздела, которого нет в резерве, его содержимое сначала читается через
   EDL и сохраняется в `backups/`.
2. Android на слоте B остаётся рабочим запасным входом. После каждой пробы
   проверяется `sys.boot_completed=1` на `_b`.
3. Разделы `modemst1`, `modemst2`, `fsg`, `fsc`, `persist`, `xbl*`, `tz*`,
   `rpm*`, `hyp*`, `abl*`, `devcfg*` не записываются. Это не ограничение
   ради осторожности: их порча не лечится без точных копий, а от них
   ничего не нужно для загрузки Linux.

## Последствия

Пробы идут подряд, журнал каждой лежит в `artifacts/`. Ранний журнал Linux
читается через EDL из раздела `logdump` (64 МиБ, пустой в штатной прошивке),
а не только через USB.
